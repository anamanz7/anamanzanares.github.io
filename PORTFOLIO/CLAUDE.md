## 🖼️ Patrones de Nombrado

- Renders: minúsculas con guiones (`render-escaparate-1-ok.png`) o mayúsculas con espacios (`1 DIA HORIZ.jpg`)
- Planos: descriptivos en español con guiones (`plano-técnico-mostrador.jpg`)
- Los archivos con espacios en nombre funcionan directamente en atributos `src` HTML
- Extensiones mixtas: `.png`, `.PNG`, `.jpg`, `.jpeg`, `.webp` — JavaScript y HTML los manejan bien

## ✅ Checklist para Nuevo Proyecto

Cuando se quiera añadir un nuevo proyecto al portfolio:

1. **Crear directorio** en `PORTFOLIO/[NOMBRE-PROYECTO]/` con subcarpetas `renders/` y `planos/`
2. **Subir imágenes** optimizadas (ver scripts de optimización)
3. **Añadir en `script.js`** — nuevo objeto en `projectsData`:
   ```js
   'id-proyecto': {
       title: 'Nombre',
       year: '2025',
       category: { es: 'Categoría ES', en: 'Category EN' },
       heroImage: 'PORTFOLIO/[NOMBRE]/renders/imagen-principal.jpg',
       description: { es: '...', en: '...' },
       renderizados: [{ src: '...', caption: { es: '...', en: '...' } }],
       planos: [{ src: '...', caption: { es: '...', en: '...' } }]
   }
   ```
4. **Añadir tarjeta** en `index.html` dentro de `.portfolio-grid-irregular`:
   ```html
   <article class="portfolio-card" data-category="categoria">
     <a href="#project/id-proyecto" class="portfolio-link" onclick="openProject(event, 'id-proyecto')">
       ...
     </a>
   </article>
   ```
5. **Actualizar versión** en `index.html`: `script.js?v=X.X.X` y `style.css?v=X.X.X` si aplica
6. (Opcional) **Añadir slide** al carrusel en `#carousel-hero`
